## 编程环境安装

### 安装jupyter

原本的docker不支持GPU加速，所以NVIDIA单独做了一个docker，来让docker镜像可以使用NVIDIA的gpu。nvidia-docker quickstart，也是直接找对应的操作系统的命令，一行行复制粘贴回车就搞定了。

```shell
sudo docker pull ufoym/deepo:all-jupyter-py36-cu100
```

```shell
mkdir -p /home/lab/Documents/iris_workspace
```

```shell
sudo docker run -d -it -p 7777:8888 --ipc=host -v /home/lab/Documents/iris_workspace:/iris_workspace --shm-size 16G --name iris_notebook  ufoym/deepo:all-jupyter-py36-cu100
```

```shell
docker exec -it 76d4f79dea sh
```

执行上面的命令会直接进入到容器，然后执行下面的命令启动```jupyter```
```shell
nohup jupyter notebook --no-browser --ip=0.0.0.0 --allow-root --NotebookApp.token=z123456 --notebook-dir='/iris_workspace' &
```
