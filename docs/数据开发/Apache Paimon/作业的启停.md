## 启停作业

### 停止作业

```
bin/flink stop --savepointPath hdfs://master:8020/directorylog c52653aa9cf450b2bfe0434f2be93a5d(flink job id)
```

保存点位置

hdfs://master:8020/directorylog/savepoint-c52653-72b749ab36e2

### 进入客户端命令

```
bin/sql-client.sh -s yarn-session -i conf/sql-client-init.sql
```
```
-- use tableau result mode
SET 'sql-client.execution.result-mode' = 'tableau';

-- switch to batch mode
RESET 'execution.checkpointing.interval';
SET 'execution.runtime-mode' = 'batch';
```
