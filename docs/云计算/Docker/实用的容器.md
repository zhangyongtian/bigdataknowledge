## MinIo

### docker部署
```shell
mkdir -p /shop/minio/data
mkdir -p /shop/minio/config
```

```shell
docker run \
   --name minio \
   -p 9000:9000 \
   -p 9090:9090 \
   -d --restart=always \
   -e "MINIO_ACCESS_KEY=123123admin" \
   -e "MINIO_SECRET_KEY=123123admin" \
   -v /shop/minio/data:/data \
   -v /shop/config:/root/.minio \
   minio/minio server /data --console-address ":9090"

docker log minio
```

## Redis管理平台

### 官网
> https://github.com/ngbdf/redis-manager

### docker部署
```shell
sudo docker run -d \
  --name mysql-container \
  -e MYSQL_ROOT_PASSWORD=root \
  -p 3309:3306 \
  mysql:5.7
```
**创建对应的数据库**
```sql
create database redis_manager;
```

```shell
docker run -d --net=host --name redis-manager  \
-e DATASOURCE_DATABASE='redis_manager' \
-e DATASOURCE_URL='jdbc:mysql://192.168.61.202:3309/redis_manager?useUnicode=true&characterEncoding=utf-8&serverTimezone=GMT%2b8' \
-e DATASOURCE_USERNAME='root' \
-e DATASOURCE_PASSWORD='root' \
reasonduan/redis-manager
```
**访问地址**
> http://192.168.61.202:8182/login

**用户名和密码**
```
admin
admin
```
