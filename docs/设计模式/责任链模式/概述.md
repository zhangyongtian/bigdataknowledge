## 定义相关类

### 定义处理公共类

```java
public interface TestProcesser<T> {
    final ScheduledThreadPoolExecutor threadPool = new ScheduledThreadPoolExecutor(1, new ThreadPoolExecutor.DiscardOldestPolicy());

    public T process(JSONObject json, T obj);

    public boolean isDone();
}
```

### 定义责任链类

```java
public class TestProcessers<T> implements TestProcesser<T> {

    private List<TestProcesser<T>> pros;

    public TestProcessers() {
        this.pros = Lists.newArrayList();
    }

    public TestProcessers(TestProcesser<T>[] pros) {
        this.pros = Lists.newArrayList(pros);
    }

    @Override
    public T process(JSONObject json, T obj) {
        T temp = obj;
        for (TestProcesser<T> pro : this.pros) {
            temp = pro.process(json, temp);
            if (null == temp) {
                break;
            }
        }
        return temp;
    }

    public void append(TestProcesser<T> pro) {
        this.pros.add(pro);
    }

    @Override
    public boolean isDone() {
        for (TestProcesser<T> pro : pros) {
            if (!pro.isDone()) {
                return false;
            }
        }
        return true;
    }

}
```
