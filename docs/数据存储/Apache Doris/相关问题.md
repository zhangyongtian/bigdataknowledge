## catalog连接问题

```
1. 偶发catalog连接mysql、oracle超时问题：

首先我们先取到日志看一下，看看是否是连接数导致的

	1. 类似日志： GetConnectionTimeoutException: wait millis 5000, active 0, maxActive 100, creating 0, createErrorCount 1055 
	2. 确定是否有网络问题


2. 偶发程序执行异常问题  报错execute sql error:communications link failure

	1. jdbc 版本过低导致，调整程序中jdbc 版本

	2. 出现这种情况时，查看be.out 中是否有以下类似提示，如果有的话在 jdbc_url 连接串后加 ?useSSL=false ：WARN: Establishing SSL connection without server identity verification is not recommended.
```

## Fe 的相关问题

### Node catalog is not ready, please wait for a while

1. 原因一，主要是元数据存储的磁盘不够了，还有默认给的jvm参数不太够。FE 挂载元数据目录的磁盘是否大于5G 这个有强规定的。
```
-Xms16g -Xmx16g  -Xmn8g
```

清理磁盘

```
sudo find / -size +100M -exec ls -lh {} \;
```
