## 解压

```shell
tar -zxvf hbase-2.4.9-bin.tar.gz -C ../module/
```

## 配置

### 修改hbase配置

```shell
vim /home/bigdata/module/hbase-2.4.9/conf/hbase-site.xml
```

```xml
<?xml version="1.0"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
<configuration>
  <property>
    <name>hbase.rootdir</name>
    <value>hdfs://bigdatacluster/HBase</value>
  </property>
  <!--
   是否集群工作
  -->
  <property>
    <name>hbase.cluster.distributed</name>
    <value>true</value>
  </property>
 
  <!--
   这里是zookeeper节点的位置
  -->
  <property>
    <name>hbase.zookeeper.quorum</name>
    <value>hadoop1:2181,hadoop2:2181,hadoop3:2181</value>
  </property>

</configuration>
```

修改regionservers文件
```shell
vim /home/bigdata/module/hbase-2.4.9/conf/regionservers
```
```
hadoop1
hadoop2
hadoop3
```

修改要启动master的机器

```shell
vim /home/bigdata/module/hbase-2.4.9/conf/backup-masters
```
```
hadoop1
hadoop2
```

### 复制hadoop配置文件到hbase
```shell
cp /home/bigdata/module/hadoop-3.2.3/etc/hadoop/hdfs-site.xml /home/bigdata/module/hbase-2.4.9/conf/
cp /home/bigdata/module/hadoop-3.2.3/etc/hadoop/core-site.xml /home/bigdata/module/hbase-2.4.9/conf/
```

### 配置环境变量
```shell
sudo vi /etc/profile.d/my_env.sh
```
```shell
#HBASE_HOME
export HBASE_HOME=/home/bigdata/module/hbase-2.4.9
export PATH=$PATH:$HBASE_HOME/bin
```

### 文件分发
```shell
/home/bigdata/shell/xsync.sh /home/bigdata/module/hbase-2.4.9
sudo /home/bigdata/shell/xsync.sh /home/bigdata/module/hbase-2.4.9
```

加载环境变量
```shell
source /etc/profile.d/my_env.sh
```

## 集群启动脚本
```shell
cd /home/bigdata/shell
vim hbase-server.sh
```

```shell
#!/bin/bash
case $1 in
"start"){
    for i in hadoop1
    do
        echo " --------启动 $i hbase-------"
        ssh $i "/home/bigdata/module/hbase-2.4.9/bin/start-hbase.sh"
    done
};;
"stop"){
    for i in hadoop1
    do
        echo " --------停止 $i hbase-------"
        ssh $i "/home/bigdata/module/hbase-2.4.9/bin/stop-hbase.sh"
    done
};;
esac
```
