```
# ssdb-server config
# MUST indent by TAB!

# absolute path, or relative to path of this file, directory must exists
work_dir = /data/app/ssdb/data
pidfile = /data/app/ssdb/data/ssdb.pid

server:
	# specify an ipv6 address to enable ipv6 support
	# ip: ::1
	ip: 0.0.0.0
	port: 8888
	# bind to public ip
	#ip: 0.0.0.0
	# format: allow|deny: all|ip_prefix
	# multiple allows or denys is supported
	#deny: all
	#allow: 127.0.0.1
	#allow: 192.168
	# auth password must be at least 32 characters
	#auth: very-strong-password
	#readonly: yes
	# in ms, to log slowlog with WARN level
	#slowlog_timeout: 5


logger:
	level: info
	output: log.txt
	rotate:
		size: 1000000000

leveldb:
	# in MB
	cache_size: 500
	# in MB
	write_buffer_size: 64
	# in MB/s
	compaction_speed: 1000
	# yes|no
	compression: yes
```

## 注意点

### 配置文件注意点
```
server:
	# specify an ipv6 address to enable ipv6 support
	# ip: ::1
	ip: 0.0.0.0
	port: 8888
```

上面配置的port的间隔是一个tab键不是空格！

### 删除数据注意

hashmap的删除是下面的方式

```java
ssdb.hclear(hashKey);
```
