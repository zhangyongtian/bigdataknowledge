## 下载安装包

### 下载安装包
```
wget --no-check-certificate https://github.com/ideawu/ssdb/archive/master.zip
```

### 解压

```
unzip master
cd ssdb-master

make
将安装在 /usr/local/ssdb 目录下

sudo make install
```

### 启动
进入到安装目录(这个目录也可以拷贝出来)
```
cd /usr/local/ssdb

cp -r /ssdb /data/app
```

启动的时候指定配置文件
```
cd /data/app

mkdir /data/app/ssdb/data

# 启动主库, 此命令会阻塞住命令行(启动前修改配置文件)
./ssdb-server ssdb.conf
或者启动为后台进程(不阻塞命令行)

./ssdb-server -d ssdb.conf


启动 ssdb 命令行

./ssdb-cli -p 8888

退出客户端

quit

停止 ssdb-server

./ssdb-server ssdb.conf -s stop


对于旧版本

kill 
cat ./var/ssdb.pid
```

### ERROR! autoconf required! install autoconf first

```
yum  install -y  autoconf
```
先执行上面的安装，如果安装不了再刷新

```
sudo yum update
```
