## 建库

```sql
CREATE DATABASE test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## docker运行mysql
```shell
sudo docker run -d \
  --name mysql-container \
  -e MYSQL_ROOT_PASSWORD=root \
  -p 3309:3306 \
  mysql:5.7
```

## docker运行redis
```shell
sudo docker run -itd --name redis-test -p 6380:6379 redis
```

## 建表
```sql
CREATE TABLE `test` (
    `id` BIGINT(20) PRIMARY KEY NOT NULL AUTO_INCREMENT COMMENT 'id字段',
    `update_time` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`) USING BTREE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> `update_time`    TIMESTAMP  NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',上面的写法是写入的时候不用给时间，数据更新的时候自动加数据，这个是默认给一个时间，上面用来导数据用。
