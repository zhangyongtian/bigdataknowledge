## docker安装kafka

```shell
docker pull bitnami/zookeeper
docker pull bitnami/kafka:2.8.1
docker pull vimagick/cmak
```

### 创建zk
```shell
docker run -itd --name zookeeper --restart=always --network=host   -p 2181:2181 -e ALLOW_ANONYMOUS_LOGIN=yes bitnami/zookeeper:latest
```

### 创建kafka
```shell
  docker run -d --name kafka -p 9092:9092 --network=host --restart=always -e JMX_RMI_PORT=9998 -e JMX_PORT=9999 -e KAFKA_HEAP_OPTS="-Xmx256m -Xms64m" -e KAFKA_BROKER_ID=0 -e ALLOW_PLAINTEXT_LISTENER=yes -e KAFKA_CFG_ZOOKEEPER_CONNECT=172.16.7.237:2181 -e KAFKA_CFG_ADVERTISED_LISTENERS=PLAINTEXT://172.16.7.237:9092 -e TZ="Asia/Shanghai" -e KAFKA_JMX_OPTS="-Djava.rmi.server.hostname=172.16.7.237 -Dcom.sun.management.jmxremote.rmi.port=9998 -Dcom.sun.management.jmxremote -Dcom.sun.management.jmxremote.authenticate=false -Dcom.sun.management.jmxremote.ssl=false"  bitnami/kafka:2.8.1
```

- 如果不指定 -Djava.rmi.server.hostname=10.253.51.157 或是会使用jmx连接kafka节点 host为localhost对应的地址。
- 如果不指定 -Dcom.sun.management.jmxremote.rmi.port=9010会在 1024-65535中随机产生

## 创建管理平台
```shell
docker run -d --name cmak --restart=always -p 9000:9000 -e ZK_HOSTS="172.16.7.237:2181" vimagick/cmak:latest
```
